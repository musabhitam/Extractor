DOCX EXTRACTOR
A simple tool that reads .docx files and saves the content
to Excel and MySQL.

REQUIREMENTS
- XAMPP (Apache + MySQL running)
- PHP 7.4+ with zip, dom, mbstring extensions


FILES
index.php       → Web interface (upload + display)
skrip2.php      → Extraction script (runs the extractor)
style.css       → Styles
script.js       → Frontend logic
docx/           → Current uploaded .docx file
backup/         → Old .docx and .xlsx files
knowledge_base_output.xlsx → Latest Excel output


HOW TO USE
1. Start XAMPP (Apache + MySQL)

2. Open in browser:
   http://localhost/extractor2/index.php

3. Upload a .docx file

4. Select category

4. Click "Extract Data"

5. View results in the table

6. Download the Excel or click any backup file
